# [play flappy bird](https://kaloodinaz.github.io/flappybird/)

If you missed the Flappy Bird 2 hype, here's your chance to try the best vintage knockoff.

**Features**

* 🎉 good ol' div's for all the objects and graphics,
* 🖥 scales perfectly on almost any screen, both mobile and desktop,
* 💩 unoptimized, laggy, and not nearly as fast as a canvas implementation,

Enjoy.

https://github.com/kaloodinaz/flappybird/ (or play [**easy mode**](https://kaloodinaz.github.io/flappybird/?easy)
